# P10000 V2 기준 제어 변경 분리 진단

현재 펌프 회귀의 원인은 아직 확정되지 않았습니다. V2는 같은 조건에서 정상이고 V3/V4/V4.5는 펌프가 시작하지 않았다는 사용자 보고를 기준으로 합니다. 세정 배출 분기는 실제 인쇄 회귀와 연결되지 않았으므로 원인으로 채택하지 않습니다.

이번에는 정상 기준 V2에 변경을 최소한으로 더합니다. V3가 교체한 잉크 초기화·커버 처리·검출·읽기/쓰기·칩 통신·ILS 조회를 한꺼번에 시험하는 대신, 내부 상태 정규화 함수 두 개만 분리합니다. **화면 전용 변경이 아닙니다.** 이 함수들은 다른 제어 코드도 읽는 내부 캐시를 바꿉니다.

| 파일 | V2에서 추가로 바뀌는 부분 |
| --- | --- |
| `DIAG_FM001PA_V2_CONTROL_STATUS.EFU` | `0x43b20014`에서 시작하는 144바이트. 상태 정상·잔량 100%·잔량 값 680,000,000·near 플래그 0으로 정규화 |
| `DIAG_FM001PA_V2_CONTROL_INFO.EFU` | `0x43b1fef4`에서 시작하는 120바이트. V3의 정품/리필/지역 정보 정규화만 적용 |
| `DIAG_FM001PA_V2_CONTROL_BOTH.EFU` | 위 두 변경을 함께 적용 |

나머지 압축 해제 모듈의 모든 바이트는 검증 기록에 있는 V2 모듈 SHA-256 `b37525fced77a59472134ff1a262d8e34e2d10cbd2fba560fcf748f95c87382f`와 동일합니다. 지정된 두 함수 범위 밖이 정확히 같은지 빌드 시 검사합니다. 원본 잉크 제어 절차와 실제 장착 검출·칩 처리·ILS 조회를 보존하며, 구동 횟수나 정지 비트를 강제로 바꾸지 않습니다. V2의 유지보수 가상화와 국가별 허용 목록 확장은 그대로입니다.

## 실기에서 구분하려는 것

첫 비교 대상은 `BOTH`입니다. V2에서 정상 동작했던 실제 잉크 장착·공급 조건을 유지해야 합니다. **잉크 미장착 가상화는 이 진단 파일에 없습니다.** 상태 캐시 정규화를 유지하는 것과 실제 칩 인증/장착 조건을 가상화하는 것은 다릅니다. 실기 검증 전이므로 정상 부팅·인쇄 또는 원하는 모든 표시를 보장하지 않습니다.

- `BOTH`가 정상이라면: 두 정규화 함수만으로는 문제가 재현되지 않습니다. 다른 V3 변경 또는 그 변경과의 상호작용이 필요하다는 근거가 됩니다. 정규화 함수가 모든 조합에서 무관하다는 뜻은 아닙니다.
- `BOTH`에서 재현된다면: V2 대비 추가 변경은 두 함수뿐이므로 `STATUS`와 `INFO`를 따로 비교합니다. 단독 변경에서 재현되는지 확인하면 원인 범위를 더 좁힐 수 있습니다.
- `STATUS`와 `INFO`가 각각 정상인데 `BOTH`만 실패한다면: 두 정규화의 결합 효과를 조사합니다.

실기 결과 없이 이 진단 후보를 해결판으로 이름 붙이거나, 실패를 특정 하드웨어 상태의 증거로 해석하지 않습니다. 정상 사용 기준은 기존 V2입니다. 펌프가 시작하지 않는 상태에서 인쇄·청소를 반복하지 않습니다.

## 로컬 검증

- V2 공개 검증 기록과 기준 모듈 해시 일치 확인.
- 네 모듈(기준 1개·진단 3개)에서 상태 7종·10슬롯의 총 280개 슬롯 사례로 원본/정규화 캐시 동작과 입력 버퍼 보존 확인.
- 원본 제어 함수 영역을 다른 용도로 재사용하지 않으며, 지정된 두 함수 외 모든 바이트가 V2와 동일함을 확인.
- EFU별 원본 압축 해제기로 모듈 전체 복원 일치, 유지보수 사용량/여유량 70호출, 외부 5블록 합계, ZIP CRC와 내부 파일 해시 확인.

패키징 시험은 실제 부팅·모터 동작 검증이 아닙니다. 변경된 대상 블록을 제조사 키로 재서명한 파일도 아닙니다. 기존 실험 빌더와 동일한 방식으로 대상 블록의 인증 메타데이터를 변경하며, 원본의 다른 블록 인증 시험에는 원본 내용 일치 대체 검사가 포함됩니다. 불명확한 외곽 수신 처리와 32바이트 후미 의미는 기존 한계로 남습니다.

재현 명령:

```bash
python firmware/P10000/build_control_isolation.py
python firmware/P10000/build_efu_research.py --control-isolation both
python firmware/P10000/build_efu_research.py --control-isolation status
python firmware/P10000/build_efu_research.py --control-isolation info
```

모듈 검증: `validation/control-isolation-build.json`

EFU 검증: `validation/control-isolation-packages.json`에 파일명·해시와 검증 범위를 기록합니다. 이 문서 작성 시점에는 실기 시험과 GitHub 업로드를 하지 않았습니다.
