# P7500 가상 카트리지 재작성

가상 시리얼·소비량 저장 코어와 원본 ARM 함수 어댑터의 개발 소스다.
**IC13/IC14에 기록하는 완성 BIN이나 실기 검증 펌웨어가 아니다.**

- [구현 범위와 재현 방법](runtime/README.ko.md)
- `runtime/virtual_cartridge.c`: 세대, 소비량, 커버 초기화, 두 뱅크 저장·복원, 논리 프로필
- `runtime/native_adapter.c`: 원본 소비량·커버·식별자·장착·잔량·유지보수 정보 및 상위 잉크 검사 작업 연결
- `runtime/native_nv.c`: 기존 NV 서비스의 소유자 논리 기록 두 개에 상태 저장·복원
- `crom.py`: 원본 CROM 프레임의 엄격한 해제와 편집 프레임 재인코딩
- `validation/`: 실제 실행한 검증 결과. 각 결과의 격리 시험 범위와 미검증 항목 참조

원본 덤프와 개인키는 포함하지 않는다. 원본 IC3/IC4가 들어 있는 사용자 소유
`IC4.zip`에서 `prepare_original.py`로 작업용 병합 이미지를 생성한다.
원본 SHA-256이 일치하지 않으면 해제·패치를 진행하지 않는다.

상위 잉크 검사·RAM 미러 경로와 네이티브 NV API 연결을 구현했다.
미해석 칩 메타데이터 전체의 영구 저장, 유지보수 칩 데이터 경로 전체, 실제 프린터의
런타임 RAM 배치·시작 훅·플래시 서비스 전원 차단 검증은 남아 있다.
현재 대체한 경로는 물리 통신 없이 동작하며,
이 방식에 ASIC/SPI 프레임 재현이 필수인 것은 아니다. 상위 네이티브
함수의 에뮬레이터 연결 시험을 실제 정품 인식·부팅·인쇄·전원 차단 복원·EFU
수용 시험으로 해석하면 안 된다. 업데이트 서명 검증은 변경하지 않았다.
