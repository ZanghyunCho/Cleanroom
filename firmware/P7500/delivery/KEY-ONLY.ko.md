# P7500 EPSONSIGN 소유자 공개키 교체 후보

사용자가 제공한 정상 부팅 원본에 소유자 공개키 두 사본만 교체한 SPI 기록용 후보입니다. 실기 부팅과 커스텀 EFU 수용은 아직 검증하지 않았습니다.

## 변경 범위

병합 이미지의 0x7010~0x704F 및 0x6D000~0x6D03F, 각 64바이트를 이전에 생성한 소유자 공개키로 교체했습니다. 원본과 소유자 공개키 모두 NIST P-256 곡선 위의 유효한 점이며 원본과 동일한 X||Y 빅엔디언 좌표 형식입니다.

그 외 바이트는 정상 부팅 원본과 전체 일치합니다. CROM은 재압축하지 않았고, 가상 카트리지·초기화 훅·NV 확장도 넣지 않았습니다. 부팅하면 원래 Epson 펌웨어 동작을 유지하는 것을 목표로 합니다. 개인키는 ZIP에 포함하지 않습니다.

## 파일과 기록

- P7500_KEY_ONLY_IC13.BIN: 물리 IC13, 원본 파일 IC3.BIN에 대응, 67,108,864바이트
- P7500_KEY_ONLY_IC14.BIN: 물리 IC14, 원본 파일 IC4.BIN에 대응, 67,108,864바이트
- manifest.json / SHA256SUMS.txt: 원본·출력·공개키 해시와 검사 범위
- owner-public.bin: 교체한 공개키 64바이트
- verify_spi_readback.py: 재독출 파일 읽기 전용 비교 도구

정상 원본을 보관한 상태에서 각 BIN을 대응 칩에 기록하고, 두 칩을 다시 읽어 출력 파일의 전체 해시와 비교합니다. 예:

```sh
python verify_spi_readback.py readback-IC13.bin readback-IC14.bin
```

기록 후 처음 켜기 전에 전체 해시 일치를 확인하면 기록 문제와 부팅 문제를 구분하는 데 도움이 됩니다. 정상 부팅 후에는 원래 펌웨어의 저장 데이터가 바뀌어 전체 해시가 달라질 수 있으므로, 부트·코드 앞부분 비교 항목도 함께 봅니다.

이번 파일은 키 교체본 한 쌍입니다. 기존 가상화 후보에서 사용했던 설치용→런타임용 전환 절차를 적용하지 않습니다. 화면·전원 LED·USB 인식 여부를 확인하고, 부팅하지 않으면 정상 원본으로 복구해 결과를 기록합니다.

## 커스텀 EFU에 대한 한계

부팅 성공은 첫 확인 단계입니다. 실제 EFU 업데이트 경로가 교체한 공개키를 사용하는지, 서명 대상 범위·파일 형식·버전 조건이 맞는지 추가 검증해야 합니다. 이 ZIP 자체는 EFU 파일이 아니며, ‘커스텀 EFU 수용 확인 완료’라는 뜻도 아닙니다. 향후 서명에는 이 공개키와 짝인 기존 소유자 PEM을 사용합니다.

실제 업데이트 검증이 교체한 키를 사용한다면 기존 Epson 키로 서명한 EFU는 그 키로 검증할 수 없습니다. 공식 업데이트와의 호환성도 미검증입니다.
