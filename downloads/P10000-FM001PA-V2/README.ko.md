# SC-P10000 FM001PA V2 시험용 EFU

이번 후보의 새 기능:
- 원본 지역 표 네 개의 호환 카트리지를 지역 설정과 무관하게 허용합니다. 잘못된 슬롯 및 무효 T코드는 거부합니다.
- 유지보수 슬롯 두 개를 가상화하여 미장착·칩 오류·가득 참 입력에도 정상/가용 공간 100%를 보고합니다.
- 유지보수 칩 확인·읽기쓰기 검사·카운터 쓰기는 가상 성공 응답을 사용하며, 상위 요청 완료 처리는 유지합니다.
- 기존 메인터넌스 사용량 0 반환 패치를 포함합니다.

포함하지 않은 것: 잉크 카트리지 미장착 상태의 가상 장착, 잉크 정품 강제 판정, 실제 Ink End Sensor 정상 강제 보고. 해당 후속 작업은 별도로 진행해야 합니다. 지역 제한 해제는 정품 검사·전체 칩 통신 가상화와 다릅니다.

검증: 원본 ARM 호출자 및 추가 코드의 지역 판정 2,070개, 유지보수 초기화·상태 통지·요청 완료, 전체 모듈 원본 압축 해제, 기존 사용량/여유량 70개, 외부 5블록 합계와 ZIP CRC를 확인했습니다. 칩 T코드는 합성 읽기, OS 메시지는 시험 훅을 사용했으며 실기 센서·통신을 시험한 것이 아닙니다. 이번 V2 EFU의 실기 설치·부팅·미장착 동작은 미검증입니다. 이전 메인터넌스 전용 EFU에 대한 사용자 성공 보고가 V2의 검증을 대신하지 않습니다.

시험은 인쇄·클리닝 없이 상태 화면부터 확인하세요. 실제 폐잉크는 계속 배출됩니다. 가상 카트리지는 폐잉크 수거를 대신하지 않으므로 물리적 탱크 또는 외부 수거 경로가 필요합니다.

이전 성공 EFU와 원본 IC2/IC3 복구 덤프를 보관하세요. SC-P10000 전용이며 FM001PA 기반입니다. 현재 표시 버전이 같아 업데이트 도구가 거부하면 오류 내용을 기록하고 중단하세요. 기록이 시작되면 완료 또는 명확한 오류까지 전원을 유지하세요. 설치 후 표시 버전, 유지보수 상태, 미장착 상태, 오류 코드와 재부팅 결과를 확인하세요.
