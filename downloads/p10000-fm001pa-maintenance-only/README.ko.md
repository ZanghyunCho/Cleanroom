# FM001PA 유지보수 사용량 조회 0 — 시험용 EFU

공식 원본을 기반으로 ARM block1 오프셋 0x13954의 8바이트만 코드 변경했다.
사용량 조회는 0, 원래 여유량 조회는 최대값 688,000,000을 반환한다.
지역·잉크·장착·칩 인증은 수정하지 않았다. 실물 유지보수 카트리지를 장착한 상태가 시험 조건이다.
조회 중 카운터 메모리 보존은 확인했지만, 후속 누적/저장 처리와 전체 표시/판정은 미검증이다.

## 중요한 한계

이전 지역 실험 EFU는 실제 업데이트에 실패했고, 공식 원본으로 복구됐다.
이번 파일도 동일한 재압축·컨테이너 재구성 방식을 사용한다.
이전 실패 원인을 해결한 버전이 아니므로 다시 Recovery 상태에 진입할 수 있다.
미확인 메인 끝 32바이트는 원본 그대로 보존했으며 장비의 검증 통과를 보장하지 않는다.
실제 장비 수락·부팅·인쇄는 미검증이다. 공식 원본의 복구 성공도 다음 복구를 보장하지 않는다.

## 시험 기록

1. 공식 원본 펌웨어와 공식 복구 도구를 보관한다.
2. 실물 유지보수 카트리지를 장착하고 현재 여유 공간 및 상태를 촬영한다.
3. SHA256SUMS.txt와 EFU 해시 일치를 확인한다.
4. 시험한다면 업데이트 수락 여부, 실패 메시지와 진행률을 기록한다.
5. 성공 시 정상 부팅, 유지보수 여유 공간 표시, 기존 잉크 상태를 확인한다.
6. 이상이 없으면 노즐 체크 후 여유 공간 표시와 정상 재부팅 후 표시를 기록한다.
7. 실패하면 같은 실험본 반복 전송을 중단하고 공식 복구 절차를 따른다.

표시 100%는 실제 폐잉크 수용량이 아니다. 물리 카트리지의 교체/관리는 계속 필요하다.
