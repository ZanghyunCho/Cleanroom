# P704 KH03P9 EFU A/B 대조군

기준은 사용자가 제공한 공식 FW4838TL.efu의 KH03P9.FY19입니다. 덤프의 KH04M4와 제품군은 같지만 버전은 다릅니다.

- A: 원본 본문 그대로, EPSONSIGN 선언 본문 길이만 실제보다 1 증가.
- B: 원본 실행 코드 그대로 CROM 첫 프레임 재압축, 두 번째 프레임 보존·재배치, 해당 섹션 합계와 SHA-1 갱신, 선언 본문 길이 +1.

두 파일 모두 원래 공개키와 서명 바이트를 보존합니다. B의 수정된 본문에 대한 기존 서명은 유효하지 않습니다. ECDSA 결과를 성공으로 대체하는 코드 패치는 없습니다. 유지보수 카트리지 기능 변경도 없습니다.

최종 EFU 재추출, ZIP CRC, 3개 섹션의 메타데이터 합계·본문 합계·SHA-1·경계, 원본 실행 코드 일치, 두 번째 프레임과 할당 경계 뒤 데이터 보존을 검증했습니다. B 토큰 패딩은 15개이며 DMA 출력 바이트 수는 48의 배수입니다.

P704 덤프 원본 ARM의 중간 수신 함수에서 남은 길이 1·검증 미완료·반환 1을 재현했습니다. 상위 수신 전체, PC 업데이트, 실제 플래시 기록·부팅, 하드웨어 Huffman/DMA는 검증하지 않았습니다. 실제 기기에서 정상 동작이 확인된 파일이라는 뜻은 아닙니다.

공식 파일·복구 수단을 확보한 별도 대조 시험용입니다. A의 업데이트와 정상 재부팅을 먼저 확인한 뒤 B를 별도로 시험해야 포장 경로를 구분할 수 있습니다.
