# SC-P5000 N005O6 좌·우 잉크 커버 논리 닫힘 — 실험용 EFU

**SC-P5000용이며 SC-P10000용이 아니다. 장비 수락/부팅/인쇄는 미검증이다.**

파일: SC-P5000_N005O6_INK-COVERS-CLOSED_UNVERIFIED.EFU
크기: 9,849,257바이트 — 첨부 공식 원본과 동일.
SHA-256: 4cf47276991e1250e2d2ca1228cf24972611fa7776da861d51d591a5e6a7b023

## 내용

원본 N005O6의 저수준 커버 조회 두 곳과 열림/닫힘 처리 네 곳을 변경했다.
초기 및 이벤트 처리에서 두 커버의 논리 상태를 닫힘으로 정규화한다.
입력 등록/원래 콜백/메시지 게시 코드와 수신 처리 호출은 보존한다.
물리 움직임은 논리 전이를 만들지 않으므로 기존 커버 전이 알림 생성은 억제한다.
따라서 카트리지 교체 후 해당 알림에 의존하는 검사/복구는 미검증이다.
실물 잉크/유지보수 카트리지 가상화 및 잔량 리셋은 포함하지 않는다.

## 포장 보존

- 원본/수정 메인 복원 크기 4,194,304바이트, 지정 6구간 외 코드 동일.
- 원본 LZSS 스트림의 두 국소 구간만 같은 길이로 재인코딩.
- RCX 전체 크기/메인 경계/기타 펌웨어 구성요소/언어 리소스 동일.
- 알려진 메인/압축/복원 가산 체크섬 갱신 및 확인.
- 외부 ZIP 원본의 151개 uncompressed DEFLATE 블록을 유지하고 해당 데이터만 교체.
- ZIP 로컬 헤더 및 중앙 디렉터리의 RCX CRC를 갱신. 전체 ZIP CRC 시험 통과.
- 모든 ZIP 항목의 이름/위치/압축 크기/메타데이터와 전체 EFU 크기는 원본과 동일.
- 인증 또는 장비 검증을 통과했다고 주장하지 않는다. 같은 크기도 수락 보장이 아니다.

## 검증 범위 및 시험

코드/모델 시험 10개와 EFU 포장 시험 4개가 통과했다.
p-code 실행 중 외부 호출은 대체했으며 실제 GPIO/IRQ/RTOS/인쇄 전체 실행은 아니다.
원본 파일과 ROM 덤프는 변경하지 않았으며 장비 전송은 하지 않았다.

시험한다면 먼저 파일 해시와 대상 모델을 확인한다. 공식 원본과 복구 도구를 보관한다.
업데이트 수락/실패 문구와 진행률을 기록한다. 성공 후에는 실물 카트리지를 장착하고
부팅·각 커버 개폐 시 표시·정상 종료/재부팅·노즐 체크를 확인한다.
이상 시 반복 전송을 중단하고 해당 모델의 공식 복구 절차를 따른다.

이 파일은 실험용이며 업데이트 실패로 Recovery 상태 또는 복구가 필요한 상태가 될 수 있다.
원래 커버 열림 정지 기능이 달라지므로 커버를 열고 손을 넣은 상태에서 인쇄하지 않는다.
