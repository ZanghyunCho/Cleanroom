# SC-P5380 / KU25Q4 — S2 전원 켜기 오류 308223 재진단

사용자는 S2부터 전원을 켤 때 시스템 오류 308223이 발생한다고 보고했다. S1은 앞서 통과했다고 보고했다. 현재 기기에 S1을 다시 적용한 뒤 정상 부팅하는지는 아직 확인되지 않았다. 오류 번호의 공식 의미나 정확한 실패 명령은 확인하지 않았다.

## 비교 순서

1. 이전에 통과한 동일 S1 파일로 복귀 부팅을 확인한다. 카트리지 장착 및 칩 상태 등은 당시 통과 조건과 같게 맞춘다. S1이 부팅하지 않으면 R1을 추가 적용하지 않고 그 결과부터 분석한다.
2. S1이 정상 부팅할 때만 R1 진단본과 비교한다. R1은 S1에 잉크 잔량 표시 100%만 추가한다. 실제 잉크 사용량은 원래대로 증가한다. S2의 사용량 0 처리, LOONA, C1, 칩 없는 동작은 포함하지 않는다.
3. R1도 실패하면 잔량 조회 변경과 그 호출 경로를 조사한다. R1이 부팅하면 S2 사용량 변경을 작은 단위로 나눠 조사한다. 어느 경우도 현시점의 원인 확정은 아니다.

R1 최종 복원 모듈은 S1 대비 offset 0x2ae88~0x2ae8f만 변경된다. 나머지 실행 모듈 바이트는 동일하다. 잔량 함수 본문을 코드 저장 공간으로 재사용하지 않는다. 기존 S1 유지보수 처리를 보존한다.

S1 재검증 1,923개, R1 최종 추출 모듈 시험 1,933개를 통과했다. ZIP CRC, 내부 섹션 합계·SHA-1·경계, 최종 코드 복원 일치, 두 번째 압축 프레임 보존을 확인했다. 이는 실제 전체 부팅 시험이 아니다. 이전 S2의 7,063개 함수 시험도 전원 켜기 경로 전체를 검증하지 못했다.

S2 및 이를 포함하는 LOONA/C1은 사용자 보고를 근거로 정상 배포본으로 취급하지 않는다. 원래 파일은 증거 보존을 위해 삭제하거나 덮어쓰지 않았다.

R1은 기존 후보와 같이 원래 공개키·서명 바이트와 선언 본문 길이 실제+1 방식을 사용한다. 수정 본문의 ECDSA 서명은 유효하지 않다.
