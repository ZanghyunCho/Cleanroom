# G2: 조건부 원본 재검증을 연결한 시험용 EFU

**실기 미장착 부팅·작동 중 제거가 해결됐다고 확인한 파일은 아니다.** 사용자 보고와 합성 ARM 상태 시험을 근거로 만든 진단 후보다. 이전 G와 혼동하지 않는다.

[G2 EFU](FW7560TL_LK29Q5-LOONA-G2.efu) · [검증 결과](FW7560TL_LK29Q5-LOONA-G2.validation.json) · [소스·시험 결과](LK29Q5-startup-G2-validation.zip)

## 변경

G2는 G의 유지보수 버스 시작·종료 생략을 유지하고, 주기 처리 끝에 원본 일반 재검증 함수를 조건부로 연결한다. 검은 배경 LOONA 로고, E/F1의 기존 변경 및 원본 공개키를 보존한다. 잉크 카트리지나 커버 센서 기능은 변경하지 않는다.

다음 조건을 모두 만족할 때만 재검증한다.

- 정상 운전 모드 값 0.
- F1에서 선택한 칩 생략 프로필 조건이 활성화됨.
- 유지보수 원시 상태가 1 또는 2.
- 현재 선택 오류가 32, 33 또는 34.

정상 상태, 다른 운전 모드, 선택 오류 0~31 및 35, 그 밖의 원시 상태는 복구 대상으로 삼지 않는다. 상태 getter를 항상 정상으로 바꾸거나 원본 검증 결과를 성공으로 대체하지 않는다. 원본 재검증 함수가 기존 상태 설정 경로를 실행한다.

## 코드 배치

104바이트 ARM 보조 코드는 F1의 고정된 프로필 조건 때문에 실행되지 않는 기존 함수 본문 안에 배치했다. 해당 함수의 원래 조건 분기와 반환 경로를 보존하고, 최종 EFU에서 추출한 모듈로 그 진입 경로도 시험했다. 모듈 크기나 BSS 영역을 늘리지 않았다.

이 배치는 F1의 프로필 조건이 항상 활성화된다는 불변 조건을 전제로 한다. 독립적인 보조 코드 패치나 F1 조건을 해제한 구성으로 사용하면 안 된다. 기존 정적 스캔에서는 이 본문으로 들어오는 외부 직접 분기/상수 포인터를 찾지 못했지만, 모든 간접 실행 가능성을 증명한 것은 아니다.

## 검증 범위

- 기존 E 회귀 395건.
- 모드 2종 × 원시 상태 8종 × 선택 오류 36종: 576개 조합. 실제 패치된 주기 함수를 실행해 조건별 호출 여부, 반환값, 레지스터 보존 및 소비 카운터 보존을 검사했다. 복구하지 않는 조합은 G와 결과가 동일함을 비교했다.
- 원본 오류 설정 함수를 사용하는 오류 12·33·34·35의 연속 처리 4건. G의 상태 유지와 G2의 조건부 회복을 비교하고 두 번째 호출에서 상태가 안정적인지 확인했다.
- 위 총 975건에 더해, 최종 EFU에서 추출한 코드로 기존 본문 소유 함수의 조기 반환 경로를 두 RAM 프로필 값에서 확인했다.
- 네 섹션의 메타데이터 합계·본문 합계·SHA-1, ZIP CRC 및 추출 왕복을 확인했다.
- 원본 ARM 로더의 파싱/DMA/LZ 복원과 본문 합계 검사를 통과했다. 하드웨어 Huffman은 완료 경계에서 모델링했다.
- F1+LOONA 기준에서 제어 모듈 슬롯 및 첫 섹션 합계·SHA-1만 변경했다. LOONA 슬롯·두 번째 제어 프레임·수신 모듈·원래 공개키와 서명 바이트를 보존했다. 선언 본문 길이는 실제보다 1바이트 크게 유지한다. 수정 본문의 ECDSA 서명이 유효하다는 뜻은 아니다.

## 확인되지 않은 부분

실제 부재/제거 시의 오류 코드와 정지 원인은 아직 실측하지 못했다. G의 버스 생략 가설도 미확정이다. 전체 부팅, 전기적 칩 제거, RTOS/인터럽트 및 UI 통지는 재현하지 않았다. 실기에서 주기 처리 자체가 정지한다면 G2의 복구 코드도 실행되지 않는다. 소프트웨어 시험 975건을 실기 성공으로 해석하면 안 된다.

## 실기 확인 순서

1. 정상 동작했던 E 또는 공식 원본 EFU를 복구용으로 확보한다.
2. 카트리지를 장착한 상태로 G2를 설치하고 정상 대기 화면까지 진입하는지 확인한다. 실패하면 복구하고 이후 시험은 진행하지 않는다.
3. 장착 상태가 정상일 때 전원을 끄고, 미장착 부팅을 별도로 확인한다. 실제 폐잉크 수거 구조를 유지한다.
4. 작동 중 제거는 별도 확인 항목이다. 인쇄·청소 등 폐잉크가 배출되는 작업 도중 수거함을 분리하지 않는다.
5. 멈춤이 반복되면 재장착과 재부팅으로 복구하고, 화면/오류/터치음/다른 도어 안내 반응을 기록한다. 동일 증상을 해결했다고 가정해 계속 시험하지 않는다.
