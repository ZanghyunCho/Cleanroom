# I1 잉크 잔량·장착/브랜딩 보고 시험본

요청 목표는 잉크 잔량 100% 유지, 사용 시 새 소비량 누적 억제, 정상 EPSON 카트리지 장착으로 보고하는 것이다. I1은 확인한 보고·누적 경로에 이 동작을 적용한 **실기 미검증 진단본**이다. 모든 정품 경고가 사라지거나 실제 칩 인증이 성공한다고 검증한 파일은 아니다.

## 기준

정상 동작이 보고된 **E+LOONA** 기준이다. 유지보수 미장착용 F1/G/G2 변경은 포함하지 않는다. 기존 E의 유지보수 관련 변경과 검은 배경 LOONA 로고는 유지한다. 한국어 글꼴과 커버 센서는 변경하지 않는다.

## 변경한 경로

1. 잉크 잔량 보고 getter는 12개 슬롯 모두 100을 반환한다. 실제 내부 상태 getter는 원본이다.
2. 원본 잉크 알림 생성기에서 정상 장착 표현과 브랜딩/적합성 분류 0을 선택하도록 한다. 출력은 원본의 정상 상태·분류 0·잔량 100 대조군과 동일하게 확인했다. 다른 종류의 통신·칩 정보·UI 경로까지 같다고 가정하지 않는다.
3. 식별한 주 소비량 증가 helper는 원본 다중 워드 누적 함수를 증가량 0으로 실행한다. 원래 저장 카운터를 읽는 getter를 0으로 바꾸지 않는다.
4. 식별한 보조/분수 소비량 증가 helper는 요청 증가량을 0으로 받는다. 원본 계산·dirty 추적 경로를 유지한다.

기존 누적 사용량을 0으로 초기화하거나 모든 복원/보정/직접 쓰기를 막는 변경은 아니다. 이미 잉크 종료·비호환·칩 통신 오류가 발생한 카트리지의 내부 오류를 일괄 지우지 않는다. 실제로 장착하지 않은 카트리지를 프린터 구동부가 받아들인다는 보장도 없다.

## 검증

- 기존 E 회귀 395건.
- 12개 슬롯 × 13개 상태 × 저장 잔량 6종: 잔량 보고 936건. 내부 상태 바이트를 보존하며 100을 반환했다.
- 두 증가 helper × 12개 슬롯 × 기존 값 3종 × 증가량 4종: 288건. 저장 카운터·분수 영역·dirty 플래그를 원본 E의 증가량 0 대조군과 비교했다.
- 상태 13종 × 브랜딩 분류 4종: 알림 52건. 원본 정상 대조군과 출력이 같고 내부 원시 상태는 유지되는지 확인했다.
- 총 1,671건의 ARM 경계 시험. 물리 칩의 정품성이나 실제 인쇄를 시험한 수치가 아니다.
- 알림 시험은 출력 버퍼 주소, 용량 숫자, 메시지 할당/전송·이벤트·로그를 fixture로 제공했다. 모든 UI 해석을 실행한 것은 아니다.
- 최종 EFU의 ZIP CRC, 네 섹션의 메타데이터 합계·본문 합계·SHA-1, 압축 해제 모듈과 시험 모듈의 일치를 확인했다.
- 원본 ARM 로더/DMA/LZ와 본문 합계 검사를 통과했다. 하드웨어 Huffman은 완료 경계에서 모델링했다.
- 원본 공개키·서명 바이트·수신 모듈과 LOONA를 보존하고 선언 본문 길이 `실제 + 1`을 유지했다. 수정 본문의 ECDSA 서명이 유효한 것은 아니다.

## 실기에서 남은 확인

장착 상태의 정상 부팅, 프린터와 PC의 잔량 표시, 인쇄·청소 후 표시 유지, 정품/호환성 경고와 OK 요구의 유무, 전원 재시작 후 상태를 각각 확인해야 한다. 경고가 남으면 메시지와 발생 시점을 기록해 별도 경로를 추적해야 하며, I1로 모든 경고가 제거됐다고 간주하지 않는다.

실제 잉크 공급과 부족 감지는 표시값만으로 판단할 수 없다. 100% 표시는 실제 충전량을 측정한 값이 아니므로 실제 잉크량을 관리해야 한다. 원본의 다른 보호 경로를 바이트로 보존했다고 해서 이 변경의 실기 동작까지 검증된 것은 아니다.

설치 전 정상 동작했던 E+LOONA 또는 공식 원본 복구 파일을 확보한다. 시작 화면 정지나 다른 이상이 있으면 복구하고 인쇄 시험을 진행하지 않는다.

SHA-256: `66de866614df4dec3019aee9a8476000b19d7ef73db5b00391ef4c762dbaa4c6`
