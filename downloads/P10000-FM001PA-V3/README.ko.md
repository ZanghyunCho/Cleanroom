# SC-P10000 FM001PA V3 시험용 EFU

V2의 사용자 정상 동작 보고를 바탕으로 잉크 가상화 후보를 추가했다. **이번 V3의 실기 설치·부팅·미장착 동작은 미검증이다.** V2 파일은 별도 폴더에 그대로 보존했다.

## 포함 기능

- V2의 지역별 호환 품번 제한 해제와 유지보수 카트리지 가상화/가용 공간 100%를 유지한다.
- 열 잉크 슬롯의 미장착 조회와 칩 확인/RW/동기화 요청을 가상 백엔드로 처리한다. 원본 상위 완료 통지는 보존한다.
- 비정품·사용 제한 관련 상태 필드를 정규화하고, 원본 정보 송신자와 JCT 수신자에서 비정품 비트가 0으로 전달되도록 한다. **실제 Epson 칩 암호 인증을 재현하거나 공장 UID를 복제한 것은 아니다.**
- 원본 진단이 `ils`로 표시하고 잉크 엔드 판정이 소비하는 비트 마스크를 정상값 0으로 보고한다. 물리 핀의 전압·극성이나 모든 직접 입력 관찰자를 검증한 것은 아니다.
- 잉크는 가상 잔량 100%와 슬롯별 가상 일련번호 `V3…`를 보고한다. 가상 단어 데이터의 변경은 실행 중 유지되지만 재부팅하면 초기화된다. 영구 저장을 구현하지 않았다.

템플릿은 지역별 클래스 2 품번을 사용하며 지역 설정이 미확정 값이면 내부 지역 4(T802x)로 초기화한다. 전체 공장 칩 메타데이터의 의미가 모두 규명된 것은 아니다. 그 중 미확정 필드는 합성 초기값을 사용한다.

## 검증한 범위

- 별도 컴파일 백엔드와 원본 필드 해독기의 읽기/품번 2,390개 및 원본 쓰기/재조회 2,310개.
- 실제 통합 V3 코드에서도 원본 77개 필드의 쓰기/재조회 2,310개, 비대상 비트 보존, 갱신 후 재조회.
- 원본 미장착 조회 요청·완료, 전체 카트리지 체크, 슬롯별 식별 정보, 상태 통지 및 JCT 정품 정보 수신.
- 원본 검출 요청의 실제 응답을 IPC 시험 경계로 상위 IKS 코드에 전달해 정상 처리됨을 확인. 반대 입력은 상위 코드가 잉크 엔드로 판정하는 대조 시험도 확인.
- 활성 디바운스 입력에서도 원본 `ils` 소비 경로가 정상 응답하는지 확인. 원시 센서 캐시는 수정하지 않는다.
- V2 회귀 시험, 기존 사용량/여유량 70개 호출, 원본 ARM 압축 해제기의 전체 복원 결과, 다섯 외부 레코드 합계, ZIP CRC와 모든 내부 파일 해시.

OS 할당·메시지 전달·완료·날짜/NV 정리에는 명시적인 시험 함수를 사용했다. 실제 NV 저장이나 실제 센서를 시험한 것이 아니다. 가상 잉크 통합 시험에는 물리 칩/암호 인증의 단순 성공 대조 함수를 사용하지 않았다. EFU 내부의 변경하지 않은 다른 인증 블록은 기존과 같이 원본 입력·태그 일치 대조를 사용했으며 실제 HMAC 재계산은 아니다.

가상 상태 1,684바이트는 제거되는 기존 커버 처리 함수 공간 `0x43b1a100`에 배치했다. 원본 MPU 초기화의 RAM 데이터 쓰기 권한, 남은 직접 분기의 내부 진입과 외부 리터럴 참조, 섹션 충돌/크기를 검사했다. 그 밖의 실행 시 무결성 검사나 모든 간접 참조까지 입증한 것은 아니다.

## 첫 실기 시험

원본 SPI 복구 덤프와 이전에 성공한 V2를 보관한다. SC-P10000 전용이며 FM001PA 기반이다. 업데이트 도구가 파일/같은 버전을 거부하면 오류 내용을 기록하고 중단한다. 기록이 시작되면 완료 또는 명확한 오류까지 전원을 유지한다.

먼저 **인쇄·클리닝 없이** 설치 후 부팅, 잉크 장착/잔량/정품 표시, 카트리지 미장착 상태, 재부팅 결과와 오류 코드를 확인한다. 상태를 정상으로 보고해도 실제 잉크 공급은 생기지 않는다. 실제 공급이 없는 상태로 인쇄·클리닝을 진행하면 헤드가 손상될 수 있다. 폐잉크 수거 경로도 유지해야 한다.
