# SC-P5380 / KU25Q4 R3 — 단일 사용량 항목 저장·증가 0 처리

사용자는 R2의 부팅 및 인쇄가 정상이라고 보고했다. R3은 실기 통과한 R2를 기준으로 같은 ID 쌍 (0x22,0x23)의 저장·증가 처리만 추가한다.

- 조회: R2와 같이 0을 반환하며 저장된 값을 지우지 않는다.
- 설정·증가: 선택 슬롯의 해당 사용량을 원본 setter를 통해 0으로 기록한다. 기존 양수 값도 해당 API가 호출되면 지워진다.
- 다른 사용량 쌍, 소수 누적 배열, ID 0x33 및 추가 누적값은 R2 그대로 유지한다.
- 모든 직접 기록이나 재부팅 복원 경로를 가로채는 구현은 아니다. 모든 사용량의 0 고정, 칩 EEPROM 초기화 및 칩 없는 동작은 아직 구현 완료로 주장하지 않는다.
- LOONA 및 C1은 포함하지 않는다.

설정·증가 함수의 원본 진입 명령을 별도 경로에서 실행한다. 대상 쌍일 때만 호출자 스택을 보존하고 별도의 0 인자 영역을 만들어 원본 setter를 호출한다. 소수 누적값은 지우지 않는다. R2의 조회 변경은 보존한다.

검증은 최종 EFU에서 다시 추출한 코드로 실행한다. S1 회귀, 10개 슬롯의 잔량 조회 및 경계 사용량/다른 ID 쌍/설정·증가 비교를 포함한다. 대상 쌍에서는 선택 사용량과 dirty flag만 바뀌는지 RAM 0x44900000~0x449fffff를 검사하고, 비대상 쌍에서는 R2와 RAM 및 결과를 비교한다. 호출자 스택 인자를 보존하는지도 확인한다. 시험용 함수 결과 대체 훅은 사용하지 않는다.

ZIP CRC·재추출, 내부 섹션 합계·SHA-1·경계, 최종 압축 복원 코드와 시험 코드 일치, 두 번째 프레임 보존을 검사한다. 실제 부팅·인쇄는 미검증이다. 기존 공개키·서명 바이트는 보존하지만 수정 본문의 서명은 유효하지 않다. 선언 길이 실제+1 방식은 이전 후보와 같다.

## 실기 비교

R2에서 통과한 동일 카트리지·칩 조건을 유지하고 R3의 전원 켜기와 인쇄를 확인한다. 문제가 발생하면 R2를 복귀 기준으로 사용한다. 정상 부팅만으로 인쇄나 소비 후 지속 상태까지 통과했다고 기록하지 않는다.
