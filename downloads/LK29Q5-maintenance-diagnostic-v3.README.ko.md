**v3도 실기에서 시작 화면 정지가 보고된 파일입니다.** 유지보수 카트리지가 장착돼 있고,
터치음·잉크 도어 열림 안내는 반응하지만 모터·펌프는 움직이지 않는다고 사용자가 확인했습니다.
정상 부팅 성공으로 확인된 버전이 아니며 분석용으로 보존합니다. v3 이후에도 공식 원본으로는
정상 부팅된다고 사용자가 확인했습니다.

[원본 동작 대조군 A/B와 시험 순서](LK29Q5-startup-controls.README.ko.md)를 준비했습니다.

## 변경

- v2의 내부 상태 조회 함수 강제 반환(상태 7)을 제거했습니다.
- 원본의 박스별 프로필 조건 함수 `0x4340ace0`가 1을 반환하도록 변경했습니다.
  관찰한 원본 분기에서는 칩 관련 처리를 생략하고 초기 상태를 0으로 설정합니다.
  이 프로필 값의 제품별 공식 의미는 확인하지 않았습니다.
- 잔량 보고는 100, 두 소비량 조회는 0을 반환하고 세 소비량 증가 함수를 생략합니다.
- 내부 상태 getter, 오류 전이, 알림 생성, 슬롯 상태 출력 및 커버 조회 함수는 원본입니다.
- 기존 비휘발성 소비량 기록을 지우지 않습니다. 실제 폐잉크 발생량이 0이 되는 것은 아닙니다.

## ARM 검증

`python research/verify_maintenance_v3.py`

74건을 통과했습니다. 24건은 원본 유지보수 초기화(`0x434051b4`), 용량 설정,
장착 조회, 동기화, 쓰기, 소비량 처리, 준비 상태와 후속 장착 전이를 연결한 시험입니다.
모델의 칩 장착/미장착, 기존 소비량 3종, 미러 데이터 2종, 프로필 바이트 2종을 조합했습니다.
원본 코드가 같은 미장착 모델에서 거부하는 대조군도 포함합니다.

기타 시험은 오류 전이 36건, 커버 상태 출력 3건, 알림 8건, 대조군 3건입니다.
상태 판정 함수의 성공 반환을 hook으로 대체하지 않았습니다. OS 지연·신호,
ROM 복사 유틸리티와 RAM/버스 데이터는 fixture입니다. 버스 begin/end 콜백은
모델에서 생략했습니다. 프린터 전체 초기화나 실제 전기적 칩 동작을 재현한 것은 아닙니다.

- 원본 로더의 기술자·DMA 설정·LZ 재구성 검사 통과. Huffman 완료 경계는 모델링했습니다.

- 본문 합계 및 내부 SHA-1 재계산, ZIP CRC와 재추출 해시 검사 통과.
- 원래 Epson 공개키와 최신 수신 모듈 보존.
- 실제 본문 159,977,472바이트, 선언 길이 159,977,473바이트(+1).
- 원래 서명 바이트는 보존했으나 변경된 본문에 대한 일반 ECDSA 검증은 실패합니다.
  수신 종료 처리와 길이 차이에 관한 연구 경로에 의존합니다.

## 실제 포장 본문의 원본 ARM 수신 검사

`python research/probe_packaged_v3_receiver.py`

EFU에서 재추출한 RCX의 EPSONSIGN부터 끝까지 원본 최신 ARM 상위 수신 함수에
입력했습니다. 모드 입력은 0이며, 실제 프린터에서 읽은 설정값이 아닙니다.
네 섹션의 원본 파서 호출, 전체 입력 소비, 상위 수신 반환 1, 서명 상태 1·남은 길이 1,
ECDSA 호출 0을 확인했습니다. 이는 서명 검증 완료를 의미하지 않습니다.

변경된 첫 섹션의 원본 SHA-1 검사가 실행됩니다. 다른 세 섹션은 원본과 바이트 단위로
동일하며, 형식별 원본 처리 경로와 호스트 합계·내부 SHA-1 검사도 확인했습니다.
원래 키와 수신 모듈 바이트가 유지됩니다.

메타데이터 작업 공간과 설치용 버퍼는 바이트 메모리로 모델링했습니다. 버퍼 용량은
실제 할당한 160 MiB로 보고하고 원본 메타데이터 기록 함수를 실행합니다.
OS 입력·메모리 유틸리티·설정 I/O·메시지 할당과 전달은 fixture입니다.
큐 0x12a의 메서드 0x3d는 원본 작업자 0x4442316c를 동기 실행하며,
작업자의 판정값을 대체하지 않습니다. 정상 헤더 1건과 잘못된 헤더 3건을 대조했습니다.
라이브러리 ID RAM 값 BA는 컴파일된 BA01J2 식별자를 근거로 둔 시험값이며,
실제 프린터 RAM에서 측정한 값은 아닙니다. RTOS 동시 실행은 재현하지 않습니다.

큰 첫 섹션을 원본 ARM 코드로 처리한 뒤 CPU/RAM 체크포인트를 저장하고
나머지 섹션을 이어 실행했습니다. 입력 해시로 체크포인트를 대조하고, 암호 상태나
서명 결과를 대체하지 않았습니다. 결과의 시간 값은 재개 구간만 나타냅니다.
기본 명령은 전체 입력을 처음부터 실행합니다.

이 결과는 플래시 설치 완료나 정상 부팅을 의미하지 않습니다.
