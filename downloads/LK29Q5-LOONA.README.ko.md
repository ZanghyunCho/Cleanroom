# LK29Q5 LOONA 부팅 로고 시험본

제공된 검은 배경 480×272 LOONA PNG의 픽셀을 그대로 사용했다. 크기 조정, 재그림, 색상 변경은 없다. 원본 ARGB 부팅 리소스의 픽셀만 교체하고 뒤쪽 코드·데이터 880바이트는 보존했다.

## 다운로드 선택

| 현재 기준 | 로고 추가 파일 |
| --- | --- |
| E — 소비량 추가 억제 기준 | [LOONA-E](FW7560TL_LK29Q5-LOONA-E.efu) |
| F1 — E + 원본 칩 생략 조건 기준 | [LOONA-F1](FW7560TL_LK29Q5-LOONA-F1.efu) |

두 파일은 순서대로 설치하는 단계가 아니다. 현재 사용하는 기준과 같은 것을 선택한다. F1 자체의 실기 성공을 이 로고 작업으로 확인한 것은 아니다. 잉크 카트리지의 700mL·정품 인식·잔량 초기화 및 커버 센서 변경은 포함하지 않았다.

## 검증 범위

- 원본 리소스는 RCX `0x21b553`, 16KiB 슬롯에 있다. 픽셀은 480×272×4바이트, 이후 코드·데이터는 880바이트다.
- 새 압축 컨테이너는 9,343바이트로 슬롯 안에 들어간다. 다음 초기화 데이터 영역을 건드리지 않는다.
- PNG 원본과 압축 후 복원한 픽셀의 완전 일치, 뒤쪽 코드·데이터 보존을 확인했다.
- 각 E/F1 기준에서 로고 슬롯 및 첫 섹션의 본문 합계·SHA-1 이외 바이트는 동일하다. 기존 유지보수 코드와 다른 모듈을 그대로 보존한다.
- 모든 4개 섹션의 메타데이터 합계·본문 합계·SHA-1 및 ZIP CRC를 확인했다.
- 원본 ARM 본문 합계 검사와 로더/DMA/LZ 복원을 통과했다. 하드웨어 Huffman은 완료 경계에서 모델링했으며 실제 하드웨어 실행은 아니다.
- 원래 공개키와 서명 바이트를 유지하고 선언 본문 길이 `실제 길이 + 1`을 유지한다. 변조 후 ECDSA 서명이 유효하다는 뜻은 아니다.

**두 새 EFU의 실기 부팅·화면 표시·PC 업데이트 프로그램·플래시 실행·전체 상위 수신 경로는 미검증이다.** 업데이트 후 정상 대기 화면까지 부팅되는지 확인하고, 시작 중 정지나 Recovery 진입 시 앞서 정상 동작한 기준 EFU 또는 공식 원본으로 복구한다. 현재 정상 동작 중인 복구 파일을 먼저 확보한다.
