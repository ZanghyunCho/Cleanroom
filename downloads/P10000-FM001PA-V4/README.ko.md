# P10000 FM001PA V4 상세 정보 표시 수정 후보

V3 정상 동작은 사용자 보고로 기록했습니다. 이 V4는 Status Monitor의 상세 정보가 ‘알 수 없음’/2000/00으로 나타나는 문제를 수정하기 위한 시험 후보입니다. V3 배포 파일은 보존했습니다.

수정:
- 미확정 칩 종류 2 대신, 원본 코드의 지역별 종류 선택을 사용합니다(지역 3은 0, 나머지는 1).

- 원시 가상 칩의 두 날짜 필드와 통지 레코드를 2026/11/04로 일치시킵니다. 이 날짜는 가상 정보이며 실제 제품 제조일·사용기한 보증이 아닙니다.
- V3의 잉크/유지보수 가상화, 정품 보고, ILS 정상 보고 및 지역 제한 해제는 유지합니다. 가상 일련번호는 그대로 유지합니다.
