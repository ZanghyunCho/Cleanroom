# SC-P5380 / KU25Q4 R4.6A — R4 + 사용량 조회 변경만

사용자는 R4.5/R4.6 적용 과정에서 시스템 오류 308223이 재발했다고 보고했다. 어느 버전에서 처음 실패했는지는 미확정이다. 이 파일은 사용자 지시에 따라 실기 통과한 R4에서 시작해 R4.6의 사용량 조회 변경만 적용한 비교본이다. 이전 R4.6 파일을 덮어쓰지 않는다.

R4 대비 실행 모듈에서 달라진 범위는 offset 0x29ba0~0x29bab의 12바이트뿐이다. (0x30,0x31) 사용량을 읽던 wrapper가 uint64 0을 반환한다. 원래 저장된 사용량과 증가 처리는 바꾸지 않는다. 이 공통 조회의 다른 호출자도 영향을 받는다. 상위 잔량 100% 및 기존 R4 동작은 유지한다.

R4.5의 제조사 EPSON 반환, 비정품 표시 플래그, 좌우 잉크 덮개 변경은 포함하지 않는다. NVRAM, 국가별 품번 선택, 로고, 실제 칩 통신 응답도 새로 변경하지 않는다. Initial Charge/CL1/CL2/CL3 모두가 실제로 통과한다는 완료 판정은 아직 하지 않는다.

## 검증

R4 기준 모듈은 기존 배포 검증 해시와 일치한다. 최종 EFU에서 다시 추출한 모듈이 R4 대비 지정된 12바이트 외에 동일한지 확인했다. S1/R4 회귀, 소수 갱신, 공통 소비 전 비교 160개 및 64비트 조회·RAM 보존 60개를 포함해 총 4,973개 시험을 통과했다. 실제 원본 ARM 판정·용량 연산을 실행하며 전역 모드와 raw 상태 등은 명시적인 합성 fixture다. 최종 ZIP CRC·재추출, 섹션 합계·SHA-1·경계, 압축 복원 코드 일치 및 두 번째 CROM 프레임 보존도 확인했다.

기존 공개키·서명 바이트는 유지하지만 수정 본문 서명은 유효하지 않다. 선언 길이 실제+1 방식은 이전 후보와 같다.

## 실기 비교

R4가 통과했던 동일 카트리지·칩 조건에서 이 후보의 전원 켜기와 인쇄를 먼저 확인한다. 정상인 경우 청소 및 해당 작업 결과를 구분해 기록한다. 308223 재발 여부가 이번 비교의 핵심이다. 이 파일의 실기 부팅·인쇄·청소 결과는 아직 미확인이다. 비교 기준 및 복귀 파일은 R4다.
