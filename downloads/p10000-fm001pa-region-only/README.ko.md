# FM001PA REGION-ONLY EXPERIMENTAL EFU

**이 파일은 지역 판정 함수만 바꾼 부분 실험본이다. 전체 가상 카트리지 펌웨어가 아니다.**

파일: `SC-P10000_FM001PA_REGION-ONLY_EXPERIMENTAL.EFU`

SHA-256: `a670c9f796c98ddefcd77fe6a3cdb373c0d210ea14e1b4446f06b1041943ba25`

## 포함된 변경

FM001PA의 압축 해제 블록1 오프셋 `0x2C794`부터 552바이트를 이전에 에뮬레이션한
지역 판정 함수로 교체했다. 알려진 지역별 제품 번호 테이블의 합집합을 사용하고,
슬롯별 색상 판정과 원래 용량 쌍은 보존한다. 디코드한 블록 크기와 실행 주소는 같다.
새 코드/RAM 또는 영구 저장 영역은 배정하지 않는다.

## 포함되지 않은 기능

- 실물 카트리지 미장착 상태의 강제 장착 인식
- 전체 UID/EPC 가상 정책 및 유지보수 가상화
- 10% 미만 커버 리셋, 가상 ID 세대 증가와 영구 저장
- 새 코어의 실기 적재·초기화·작업 잠금

따라서 이 EFU로 ‘카트리지 없이 인쇄’ 목표가 구현됐다고 해석하면 안 된다.
기존의 칩 없는 ARM 코어는 별도 실험 자료이며 이 EFU에 들어 있지 않다.

## 파일 수준 검증

- 원본 SHA-256 및 패치 코드 SHA-256 확인
- 수정 블록 LZSS 재압축→별도 디코더 복원→바이트 비교
- 디코드한 코드에서 552바이트 외 부분 동일
- 나머지 두 ARM 블록과 다른 네 펌웨어 구성요소, 언어 리소스 동일
- 블록/메인 컨테이너의 확인된 길이·가산 체크섬 갱신 및 검증
- EFU 내부 ZIP 전체 CRC 검사
- 재압축 및 포장 시험 6개 통과

메인 영역 마지막 32바이트는 용도를 확인하지 못해 원본 그대로 보존했다.
이 필드가 수정 이미지 검증에 사용되는지 확인하지 못했다. **업데이터 수락, 동일 버전
업데이트 허용, 장비 측 무결성 검사, 부팅, 인쇄는 미검증이다.** 이 파일은 검증된 실기
펌웨어라고 표시하지 않는다.

이 부분 실험본은 수정된 EFU 컨테이너의 수락 여부를 확인하는 독립 단계다.
전체 가상화본에는 메모리/저장 배치와 실제 작업 잠금 등 해결되지 않은 문제가 남아 있다.
