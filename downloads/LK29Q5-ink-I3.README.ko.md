# I3: 두 번째 잉크 상태 보고의 브랜딩 필드 정합

사용자는 I1에서 잔량 100% 표시가 작동하지만 I2에서도 비정품 경고가 남는다고 보고했다. 현재 화면의 모델명은 **T44L 계열**, 실제 기준 용량은 사용자 확인으로 **700mL**다. 이전 T44U 정보는 정정한다.

I3는 실기 원인을 확정한 해결본이 아니라, 새로 확인한 보고 경로 불일치를 분리하는 **실기 미검증 후보**다.

## 이번에 찾은 차이

I1의 비동기 잉크 알림 생성기 `0x433f3378`과 별도로, 원본에는 동기 상태 보고 생성기 `0x4340f7b0`가 있다. 두 함수 모두 원래 브랜딩 분류 getter `0x434033d4`를 사용한다. I1은 첫 번째 함수 안의 분류값만 0으로 바꿨고, I2의 추가 승인 변경도 두 번째 함수의 출력은 바꾸지 않았다.

두 번째 함수는 슬롯당 12바이트 레코드를 만든다. 그 안의 `+4` 32비트 필드에 원래 분류값을 기록한다. 합성 정상 상태·브랜딩 값 1에서 I2의 첫 슬롯은 다음과 같았다.

```text
I2: 01 01 00 00  01 00 00 00  00 00 00 00
I3: 01 01 00 00  00 00 00 00  00 00 00 00
```

I3는 이 동기 보고 생성기의 `0x4340f82c` 명령 한 개를 변경해 **보고되는 브랜딩 필드만 0**으로 만든다. 비동기 알림과 원본 정상 대조군의 분류값에 맞춘다. 이 보고 함수는 두 원본 호출 지점 `0x43410f88`, `0x43410fd0`에서도 참조된다.

실제 경고 UI가 이 필드를 사용했다는 물리 추적은 아직 없다. 따라서 이 차이가 실제 경고의 유일한 원인이라고 단정하지 않는다.

## 유지하는 동작

- I1의 잔량 100% 보고와 식별한 두 소비 증가 경로, I2의 특정 NoLogo 승인 조회 변경, E 유지보수 변경 및 LOONA 로고.
- T44L 모델/SKU와 용량 조회 표. 모델명을 T44U나 다른 이름으로 바꾸지 않았다.
- 동기 보고의 다른 장착/동작/승인 요구 필드, 원시 상태 getter와 입력 캐시.
- 별도 `AcceptAreaOut` 승인 경로 및 레코드 0x29. 지역 승인도 무조건 통과시키는 변경은 하지 않았다.
- 커버 센서·한국어 폰트 및 원본 칩 통신/명시적 오류 경로.

G/G2 유지보수 미장착 변경은 포함하지 않는다. 실제 칩의 제조사 데이터나 암호 인증을 정품으로 만드는 작업이 아니다.

## 검증

- I2의 기존 9,160건을 I3 코드에서 재실행했다.
- 원시 상태 13종 × 브랜딩 4종 × 커버 RAM 값 2종 × 모드 2종 × 내부 분류 3종 = 동기 상태 조합 624건. 각 조합에서 원본 동기 함수가 12개 슬롯 전체의 레코드를 생성하도록 실행했다.
- 모든 조합에서 I2 대비 슬롯별 `+4` 필드만 0으로 바뀌며, 다른 필드·반환값과 원시 입력 캐시는 보존되는지 확인했다.
- 총 9,784건은 합성 RAM의 원본 ARM 경계 시험이다. 실제 인쇄·전체 UI 해석·부팅·전기적 칩 동작을 재현한 수치가 아니다.
- 최종 EFU 압축 해제 모듈과 시험 코드 일치, 두 번째 CROM 프레임 보존, ZIP CRC, 네 섹션 합계·SHA-1, 원본 ARM 로더/DMA/LZ와 본문 합계 검사를 확인했다. 하드웨어 Huffman은 완료 경계에서 모델링했다.
- 원래 공개키·서명 바이트·수신 모듈·LOONA를 보존하고 선언 본문 길이 `실제 + 1`을 유지했다. 수정된 본문의 ECDSA 서명이 유효한 것은 아니다.

## 실기 확인

정상 동작했던 I1 또는 E+LOONA 복구 파일을 확보한 뒤 장착 상태로 설치한다. 정상 부팅, T44L 모델 표기, 잔량 100%를 먼저 확인한다. 실제 잉크 공급을 유지하면서 연속 인쇄와 재부팅 후 인쇄에서 확인 메시지가 반복되는지 본다.

경고가 남으면 정확한 문구와 발생 시점, 소모품 정보 화면의 정품 표시를 기록해야 한다. 다른 지역/호환성/명시적 오류까지 해결됐다고 가정하지 않는다. 실제 잉크량은 표시값과 별도로 관리한다.

SHA-256: `9334a7f8995f5ab49419c29ecff5db077b1132b2296f6a7e53806d65dfee7eab`
