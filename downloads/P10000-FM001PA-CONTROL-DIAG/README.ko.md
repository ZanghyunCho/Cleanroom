# SC-P10000 FM001PA 제어 변경 분리 진단

**원인 분리용 진단 EFU입니다. 실기 성공을 확인한 해결판은 아닙니다.**

**먼저 [BOTH](BOTH/README.ko.md)를 받으세요.** 원본 제어를 보존한 V2에 잔량·상태와 정품 정보 정규화 두 함수만 추가했습니다. V2가 정상 동작했던 것과 같은 실제 장착·잉크 공급 조건에서 비교합니다. **잉크 미장착 가상화는 포함하지 않았습니다.**

| 파일 | 비교 목적 |
| --- | --- |
| [BOTH](BOTH/README.ko.md) | 두 정규화 함수를 함께 적용; 첫 비교 대상 |
| [STATUS](STATUS/README.ko.md) | 잔량·상태 정규화만 적용 |
| [INFO](INFO/README.ko.md) | 정품/리필/지역 정보 정규화만 적용 |

각 폴더의 분할 파일 세 개를 전부 다운로드하여 같은 폴더에 놓고, **7-Zip에서 `.zip.001`을 열어 해제**하세요. 각 파일 페이지에서 Download raw file을 누르세요. 우선 BOTH 세 파일만 받으면 됩니다.

BOTH가 정상이면 다른 V3 변경 또는 상호작용 쪽으로 범위를 좁힐 수 있습니다. BOTH에서도 재현되면 STATUS와 INFO를 따로 비교합니다. 세 파일을 한꺼번에 설치하는 방식이 아닙니다.

펌프 강제 구동·정지 비트 해제는 넣지 않았습니다. 내부 캐시 변경이며 화면 전용 변경은 아닙니다. 정상 사용 기준은 기존 V2입니다.
