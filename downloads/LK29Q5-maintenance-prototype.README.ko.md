## ARM 시험에서 확인한 동작

- 유지보수 박스 잔량 100 보고.
- 두 소비량 조회값 0 보고 및 추가 누적 중단.
- 사용 가능 반환값 1과 원본 일반 정상 상태와 동일한 알림.
- 오류 인덱스 36개 × 기존 카운터 2종의 72건 및 알림 비교 8건 통과.

합성 RAM으로 관련 원본 ARM 함수 경로를 실행한 결과입니다.
실제 칩 미장착 상태에서 프린터가 정상 작동한다고 확인한 결과는 아닙니다.
기존에 저장된 소비 이력은 삭제하지 않습니다.

## 포장 및 서명 상태

제어 모듈 56바이트를 변경하고 CROM 재압축·재추출 일치를 확인했습니다.
다른 CROM 프레임과 원래 Epson 공개키, 최신 수신 모듈은 보존했습니다.
변경한 섹션의 내부 SHA-1 검사값을 다시 계산했으며 ZIP CRC도 통과했습니다.

원래 서명 바이트는 유지했지만 본문 변경으로 일반 ECDSA 검증은 실패합니다.
선언 본문 길이는 요청된 연구 조건에 따라 실제보다 1바이트 크게 지정했습니다.

| 항목 | 바이트 |
|---|---:|
| 실제 본문 길이 | 159,977,472 |
| 선언 본문 길이 | 159,977,473 |

이 길이 처리 경로는 최신 원본 ARM 코드의 합성 시험에서 재현했습니다.
실제 EFU·PC 업데이터·프린터 조합의 수락을 입증한 것은 아닙니다.
하드웨어 CROM 해제기와 전체 부팅 동작도 미검증입니다.
