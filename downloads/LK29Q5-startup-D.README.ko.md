# LK29Q5 진단용 D: C에 수명 종료 검출 두 곳만 추가 변경

사용자는 C에서 정상 작동과 낮은 잔량의 100% 표시를 확인했습니다. 수명이 종료된
카트리지는 여전히 수명 종료로 표시된다고 보고했습니다. 이 결과는 수치 잔량 보고와
수명 종료 검출이 별개라는 소프트웨어 분석과 일치합니다.

**D의 실기 부팅·수명 종료 카트리지 동작은 아직 미검증입니다.**
C의 잔량 보고 변경을 유지하고, 알려진 수명 종료 검출 두 곳만 추가 변경합니다.
소비량 0 처리와 카트리지 미장착 동작은 아직 포함하지 않습니다.

## 추가 변경

| 주소 | C 대비 변경 | 목적 |
| --- | --- | --- |
| `0x43405998` | `moveq r4,#1` → `moveq r4,#0` | 원본과 같은 기록 읽기를 수행하되, 관찰한 수명 비트 검출에서 만료를 반환하지 않음 |
| `0x43406b54` | `movls r0,#1` → `movls r0,#0` | 실제 카운터와 상한은 읽되, 상한 도달 시 full 판정을 반환하지 않음 |

C보다 실제 코드 바이트 2개가 더 바뀝니다. 공식 원본 대비 총 5바이트, 명령 위치
3곳이 다릅니다. 프로필이나 원시 상태를 강제로 정상으로 바꾸지 않습니다.
카운터 읽기·증가, 칩 통신·동기화, 커버 확인, 다른 오류 처리는 원본입니다.
근접 상한 경고도 원본으로 남깁니다. 오류 선택기 자체나 오류 35를 전역 차단하지
않으므로, 분석되지 않은 다른 경로에서 같은 오류가 발생할 가능성은 남아 있습니다.

EEPROM/비휘발성 수명 기록을 지우거나 초기화하지 않습니다. 원본 펌웨어로 되돌리면
원래의 수명 판정이 다시 적용됩니다. 수명 종료된 카트리지의 물리적 폐잉크 수거
능력을 복구하는 것은 아니므로 실제 수거 상태는 별도로 확보해야 합니다.

## ARM 및 포장 검사

- C 동작 회귀 검사 87건, 수명 비트 전이 8건, 사용량 경계 7건, 준비 상태 16건: 총 118건 통과.
- 합성 수명 비트 조건에서 C는 상태 7로 전이하지만 D는 같은 기록을 읽고 원래 상태를 유지합니다. 미러/비휘발성 캐시 바이트는 바뀌지 않습니다.
- 합성 상한 도달/초과 카운터에서 D의 full 판정은 0이고 준비 검사는 1입니다. 내부 카운터를 0으로 속이거나 실제 증가를 중단하지 않습니다.
- 미장착·초기화 미완료·다른 오류 상태의 준비 거부가 유지됩니다. 수명 판정이나 준비 함수의 반환값을 hook으로 대체하지 않았습니다.
- 네 섹션의 메타데이터/본문 합계와 내부 SHA-1, ZIP CRC 및 압축 해제 모듈 바이트 비교 통과.
- 원본 ARM 합계 함수로 첫 섹션 117,047,296바이트 검사 성공(1).
- 원본 로더의 기술자·DMA·LZ 재구성 통과. Huffman 완료 경계는 모델링했으며 실제 하드웨어 처리 시험은 아닙니다.

제공된 공식 원본·원래 Epson 공개키·원래 서명 바이트·최신 수신 모듈은 보존합니다.
본문 변경으로 일반 ECDSA 검증은 실패하며, 선언 본문 길이 +1 경로에 의존합니다.
이번 D 전체 입력을 ARM 상위 수신 함수로 다시 재생하거나 전체 부팅을 실행한
결과는 아닙니다. 실제 카트리지의 모든 거부 원인을 제거했다고 확인한 것도 아닙니다.

## 실기 확인 순서

1. 정상 카트리지를 장착한 상태에서 D로 업데이트한 뒤 정상 부팅과 100% 표시를 확인합니다.
2. 정상 교체 절차로 수명 종료 카트리지를 장착하고, 인식 결과와 수명 종료 메시지 유무를 확인합니다.
3. 다른 오류나 정지가 생기면 정상 동작이 확인된 C 또는 공식 원본으로 되돌리고 결과를 기록합니다.
