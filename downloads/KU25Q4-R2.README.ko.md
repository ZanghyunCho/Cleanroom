# SC-P5380 / KU25Q4 R2 — 단일 사용량 항목 조회만 변경하는 진단본

사용자가 R1의 전원 켜기·인쇄·잔량 100% 표시를 실기 통과했다고 보고했다. 이 결과를 기준으로 S2의 사용량 변경을 분리한다. S2부터 전원 켜기 오류 308223이 발생했다는 보고도 유지한다.

R2는 R1에 한 가지 동작만 추가한다. 일반 40비트 사용량 조회 API에서 ID 쌍 (0x22,0x23)이 정확히 일치할 때만 반환 레지스터 r0/r1을 0으로 만든다. 다른 쌍은 원래 조회 함수로 진행한다. 저장된 사용량을 지우지 않으며 설정·증가·소수 누적값·추가 누적값·ID 0x33은 R1 그대로다. 따라서 모든 사용량 0 고정 기능이 완성된 후보가 아니다. 사용자 화면에 모든 사용량이 0으로 표시된다고 주장하지 않는다.

실행 모듈은 R1 대비 두 범위만 바뀐다. 조회 함수 진입점 0x13df0의 4바이트와 이미 반환하는 잔량 조회 함수 뒤 0x2ae90의 28바이트다. 해당 공간 외부의 직접 분기 및 절대 주소 참조를 검사한다. 동적 실행 전체의 검증은 아니다.

최종 EFU 추출 모듈로 S1 회귀 1,923개, 잔량 100% 10개, 사용량 조회·설정·증가 비교 900개, 총 2,833개를 통과했다. 정확한 대상 쌍, 다른 쌍 및 한쪽 ID만 같은 쌍을 비교했고 10개 슬롯·경계 사용량을 확인했다. RAM 영역 0x44900000~0x449fffff와 호출자 스택 인자를 비교했다. 원본 함수의 결과를 시험 훅으로 대신 반환하지 않았다.

ZIP CRC, 재추출 일치, 내부 섹션 합계·SHA-1·경계, 압축 복원 코드 일치 및 두 번째 프레임 보존을 검사했다. 실제 전체 부팅·인쇄는 아직 미검증이다. 기존 서명 바이트는 보존하지만 수정 본문 서명은 유효하지 않으며 선언 길이 실제+1 방식은 이전 후보와 같다.
