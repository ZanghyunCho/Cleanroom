# P704 Stage 1: 장착 유지보수 카트리지 잔량 100% / 소프트웨어 사용량 0

기준: 공식 FW4838TL.efu, KH03P9.FY19. 제공된 덤프는 KH04M4로 버전이 다릅니다.

사용자는 유지보수 카트리지의 폐잉크를 외부로 배출하는 조치를 완료했다고 설명했습니다. 이 파일은 장착 카트리지의 소프트웨어 사용량과 보고 경로를 수정한 첫 시험본입니다. 실제 기기의 업데이트·부팅·인쇄와 물리 칩 기록은 미검증입니다.

## 동작

- 두 사용량 채널 ZA/YA의 알려진 소프트웨어 설정 읽기와 쓰기를 0으로 정규화합니다. 설정 ID는 0x103d/0x103f이며 원본 OS 설정 접근 경로를 유지합니다.
- 칩 캐시에서 읽은 사용량을 0으로 보고하고, 해당 사용량 필드를 쓰는 함수도 0을 기록하도록 수정합니다. 동기화용 캐시 읽기 역시 0으로 맞춥니다.
- 사용량에 따른 near/full 비트의 읽기·쓰기만 0으로 정규화합니다. 일반 잉크 카트리지 사용량은 변경하지 않습니다.
- 유지보수 잔량 이벤트는 100%, 사용량 이벤트는 0을 저장·보고합니다. IKS의 정상 잔량 계산도 100%로 유지합니다.
- 카트리지 미장착 동작은 구현하지 않았습니다. 장착 감지·칩 식별·통신 전송·다른 칩 오류·커버 처리 코드는 보존했습니다.

ZA/YA는 사용량 채널 명칭이며 서로 다른 물리 카트리지 두 개라는 뜻으로 단정하지 않습니다. 제공된 펌웨어에서 확인한 공통 유지보수 경로를 수정했습니다.

이 패치는 펌웨어가 보는 사용량을 0으로 고정하는 방식입니다. 이미 칩이나 비휘발성 저장소에 들어 있는 물리 셀을 일괄 소거하는 리셋 도구가 아닙니다. 실제 EEPROM/칩 쓰기의 수락 여부, 원본 펌웨어로 복귀했을 때의 값은 실기 확인이 필요합니다.

## 검증

- KH03P9 제3 섹션 CROM의 실행 명령 29곳, 실제 바이트 86개 변경. 나머지 코드 바이트 보존.
- 원본 및 수정 ARM 명령을 Unicorn에서 실행한 125개 시나리오 통과. 소프트웨어 설정 기존값/새 값, 칩 캐시 32비트 경계값, 반복 쓰기, 사용량 플래그, 동기화 값, 잔량·사용량 이벤트, 용량 경계, 장착 상태 및 오류 상태 보고를 비교했습니다.
- 테스트의 OS 설정 읽기/쓰기와 보고 전송 경계만 RAM/메시지 모델로 처리합니다. 카운터 함수나 장착 판정의 반환값을 성공으로 대체하지 않았습니다. 실제 RTOS, 물리 칩 및 전체 인쇄 시험은 아닙니다.
- 최종 EFU에서 다시 꺼낸 코드가 시험 코드와 정확히 일치합니다. 3개 섹션 합계·SHA-1·경계와 ZIP CRC 통과.
- 원본 Huffman 테이블로 재압축, 토큰 패딩 14개, 패딩 포함 DMA 크기 48바이트 배수 확인. 두 번째 압축 프레임과 복원 결과 보존. 실제 하드웨어 Huffman/DMA는 실행하지 않았습니다.
- 첫째·둘째 섹션 본문, 공개키 및 원본 서명 바이트 보존. 선언 본문 길이는 실제 +1입니다. 수정된 본문의 기존 ECDSA 서명은 일반 검증에서 유효하지 않으며, 수신 길이 제어 흐름에 의존합니다. ECDSA 성공 반환 패치는 없습니다.

## 실기 확인

장착 상태에서 업데이트 후 정상 부팅과 잔량 100%를 확인하고, 같은 카트리지로 출력/청소 전후 사용량을 비교합니다. 화면 표시만으로 실제 칩 기록이나 모든 사용량 경로가 동결됐다고 판단하지 않습니다. 이상 발생 시 검증된 복구 경로로 공식 파일 또는 정상 동작이 확인된 대조군으로 복귀합니다.

소프트웨어 시험은 통과했지만 실제 P704에서의 성공 결과는 아직 없습니다. 검증 결과 JSON에 시험 범위와 변경 위치를 기록했습니다.

## 재현

원본 FW4838TL.efu/RCX와 복원 모듈을 /workspace/p704-analysis 아래 준비한 작업 공간에서:

    /workspace/cleanroom-tools/bin/python stage1/verify_stage1.py
    /workspace/cleanroom-tools/bin/python stage1/build_stage1.py

검증 ZIP에는 빌드·검증 코드와 CROM 디코더/인코더가 포함됩니다. 원본 입력 파일은 중복 포함하지 않았습니다.
